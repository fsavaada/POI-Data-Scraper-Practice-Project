# 大众点评全国必吃榜餐馆数据

## 采集口径

- 来源为用户指定的2026年必吃榜公开页面，按其默认综合展示顺序每城市取最多20家，并非官方名次排名。
- 城市目录来源：<https://plat.dianping.com/mapi/shoprank/mustseriescitylist.bin?rankId=136&platform=1&pageCityId=4>。
- 仅使用榜单 `shopIds` 中的餐馆。不上榜的普通餐馆不会用于补齐，不足20家不强求。
- 全国范围包含大陆31个省级地区、香港、澳门、台湾。台湾仅包含当前目录中的台北入口，不代表覆盖台湾所有城市。
- 顺德为佛山市下辖区，不另作为城市计数；佛山仍限20家。
- 城市覆盖表将“未列入当前目录”“资料未获取”和“榜单实际不足20家”分别记录。不在目录不能解释为没有餐馆。

## 字段及缺失规则

- 店铺名、5分制评分、人均消费、特色菜来自榜单原始字段；特色菜为用户推荐标签，不代表完整菜单。
- 人均消费保留大众点评的元/人展示数值，不自行进行汇率转换。
- 街道门牌地址来自同一店铺ID的公开相册页。
- 省市名称使用行政区划参考表匹配。区县通过榜单行政区与商圈层级关系、原始地址明确的区县前缀，或榜单县级城市入口中的同一店铺ID核验。不能唯一匹配则为空，不根据店名猜测。
- 行政区参考表：<https://github.com/modood/Administrative-divisions-of-China> 的 `dist/pca-code.json`。该表为参考快照，可能不包含最新变更；不强行映射新区、功能区或旧地名。
- 重庆“两江新区”已按[重庆市民政局2025年区划代码变更公告](https://mzj.cq.gov.cn/zwgk_218/zfxxgkml/tzgg/202512/t20251205_15215632.html)补充为代码500157，不继续使用已撤销的江北区、渝北区代码。仅在店铺榜单地区归属明确时采用，不批量猜测原北碚区餐馆的新归属。
- 东莞、中山为不设区县的地级市，不虚构区县；若公开来源能核实直管镇街，其名称保留在地区列并以地址完整性说明真实层级。海南省直辖县级目的地保留其实际层级。
- 主表保留独立的省份、城市、区县及地址状态，便于筛选不完整地址。无法确认的区县不会隐藏在完整地址中。
- CSV使用UTF-8 BOM编码。缺失字段留空，不填为0、不生成占位餐馆。

## 文件

- `restaurants.csv`：餐馆明细及来源链接。
- `city_coverage.csv`：各城市的榜单目录数量、实采数量和状态。
- `quality_report.json`：去重、数量上限、字段缺失检查结果。
- `boards/`、`shops/`：公开页面原始缓存，便于复核和断点续采。

## 运行

在项目根目录执行：

```powershell
python -m Dianping_Spider --workers 3
python -m unittest discover -s tests -v
```

程序复用已有缓存。遇到验证或请求失败会记录缺失，不尝试绕过。刷新时应先归档本批缓存，避免混合不同采集时间。Git与发布ZIP仅包含最终结果及精选参考元数据，不包含原始网页；从发布包首次运行会重新采集。
